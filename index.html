How it works

Five steps from file to evidence

Upload, hash, timestamp, certify, vault. Your confidential file stays off-chain. Only a cryptographic commitment is anchored.

  1. Upload

    Add a document, image, code, design, recording or AI output, plus a title and creator declaration.

  2. Hash

    The file is converted into a unique SHA-256 fingerprint. Change one byte and the fingerprint changes completely.

  3. Timestamp

    The fingerprint is batched into a Merkle tree and the root is anchored to a public blockchain.

  4. Certificate

    You receive a Certificate of Existence with the hash, recorded time, chain reference and verification steps.

  5. Vault

    Versions, audit events and evidence snapshots stay organized in your custody record for later use.

What IP Custody is not. A Certificate of Existence does not replace a patent application (USPTO), copyright registration (U.S. Copyright Office), trademark registration (USPTO) or advice from an attorney. It records that a file existed at a point in time. It does not decide ownership, inventorship, novelty or patentability. What it proves and what it doesn't.
