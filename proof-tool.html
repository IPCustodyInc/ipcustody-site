Hash & Proof Tool

Compute a SHA-256 fingerprint of a file or text on your own device, download a self-generated hash receipt, and later check that a file still matches. Nothing is uploaded, and this page makes no network requests.

Self-generated, not certified. Receipts from this tool are not a blockchain timestamp and not an IP Custody certificate. The time comes from your device clock and isn't independently verified. A receipt shows what a file's fingerprint was; it doesn't prove when the file was created, who made it, or ownership. It is not a registration and not legal advice.

How it works

  • SHA-256 turns any file into a 64-character fingerprint. The same bytes always give the same fingerprint, and changing a single byte gives a completely different one.
  • Local only. This page uses your browser's built-in Web Crypto API. Your file is read in memory and never uploaded, stored or sent anywhere. The page loads no third-party scripts.
  • Receipts are files you keep. The JSON and TXT receipts are generated in your browser and saved to your device. They don't include the file itself (or the text you hashed).
  • Check any time. You can also verify a hash with standard tools: shasum -a 256 file (macOS/Linux) or certutil -hashfile file SHA256 (Windows).

What makes a record stronger

A self-generated receipt relies on your own device clock. An independent time reference, such as a public blockchain anchor, is harder to dispute. That is what IP Custody's planned Certificate of Existence is designed to add, with a custody record and verification steps.
